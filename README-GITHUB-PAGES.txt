WATAGACHI ERP — GitHub Pages package

To publish with GitHub Pages:
1. Extract this ZIP.
2. Upload the extracted files and folders to the root of bransonmanning-prog/WATAGACHI.
3. In GitHub, open Settings > Pages and select the branch and /(root) as the source.
4. Save and wait for Pages to publish.

The site uses the Supabase project configured in supabase-config.js. That file contains the public publishable key, not a service-role secret. Supabase holds live ERP records in its database; GitHub stores this site's code and the included SQL schema file.
